# Sendai SSG
A simple "static site generator" using [Python](https://www.python.org/) and [Pandoc](https://pandoc.org/). Convert your Markdown files into HTML while having hands-on configuration of your website.

Please note that Sendai is still in *early* development!
## How To Use
1. Have [Pandoc](https://pandoc.org/installing.html) installed.
2. Clone this repository.
3. Place Markdown files into the input folder.
4. In terminal, run `python3 __main__.py`.
5. Voila! Find your HTML files in the output folder.
6. Configure how you want your website to look via templates and CSS.
